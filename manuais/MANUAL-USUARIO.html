1. Primeiro contato: o que é este programa?

O WMK Retro Studio permite desenhar um mapa 2D com blocos (tiles) e testá-lo em primeira pessoa, num FPS 2.5D leve. Não precisa saber programar para desenhar sua fase. É um protótipo educativo e experimental.

2. Instalar no Windows (passo a passo)

  1. Acesse o GitHub do projeto e clique em Code → Download ZIP.
  2. Extraia o ZIP para uma pasta sua, por exemplo D:\Ferramentas\WMK-RETRO-STUDIO.
  3. Abra a pasta extraída e dê duplo clique em INICIAR-WINDOWS.cmd. Ele abre o index.html no navegador padrão.
  4. Se o Windows advertir sobre execução de scripts, é possível abrir index.html manualmente no Chrome/Edge.
  5. Clique em Mapa exemplo e em JOGAR FPS.

Não é necessário instalar Python, Node, Unity, Godot ou bibliotecas. O aplicativo funciona localmente, com arquivos HTML/JavaScript. Um servidor HTTP estático pode ajudar se seu navegador restringir recursos ao usar file://.

3. Linux e macOS

Extraia o projeto e abra index.html em um navegador moderno. Opcionalmente, dentro da pasta rode python3 -m http.server 8000 e abra http://localhost:8000.

4. Entendendo a tela

5. Desenhando sua primeira fase

  1. Selecione paredes e escolha tijolo, metal, pedra ou outro tile.
  2. Pinte corredores, deixando os espaços livres para circular.
  3. Selecione objetos para posicionar o jogador, chaves, inimigos, munições e saída.
  4. Experimente uma porta azul e uma chave azul. A porta exige a chave correspondente.
  5. Clique em Validar mapa para detectar problemas básicos.
  6. Clique em JOGAR FPS e teste sua fase.

7. Tilesets e camadas

Um tileset é uma imagem com vários blocos. No editor, selecione o tamanho (16, 32, 64 ou 128 pixels) e carregue uma spritesheet PNG/JPG/WebP. O programa recorta até 64 tiles por importação para aplicação como texturas de parede. Camadas disponíveis: piso, paredes, decoração e objetos; cada uma possui visibilidade e bloqueio.

Imagens de terceiros têm licenças próprias. Baixe pacotes de fontes confiáveis, como Kenney, e confira as condições do pacote específico. Não use sprites de Mario, Doom, Sonic ou outros jogos comerciais em projetos redistribuídos sem autorização.

8. Personalização dos painéis

  1. Arraste um painel por sua barra de título para alterar a posição.
  2. Use o canto inferior direito para mudar tamanho.
  3. Clique em Layouts, digite um nome e escolha Salvar novo.
  4. Para alternar, selecione um nome na lista e clique Carregar.
  5. Use Atualizar selecionado, Renomear ou Excluir para manutenção.
  6. Use Exportar JSON para backup e Importar JSON para mover a outro computador.
  7. Restaurar padrão recria a distribuição inicial.

A última distribuição é restaurada automaticamente no mesmo navegador. Presets de layout e arquivos do mapa são independentes.

9. Salvando mapas e não perdendo trabalho

Use Salvar JSON para baixar o arquivo da fase e Abrir JSON para restaurá-lo depois. Salve frequentemente: o mapa não é armazenado automaticamente no navegador. Layouts são salvos automaticamente, mas devem ter backup se forem importantes.

10. Problemas comuns

SintomaComo resolver
Tela brancaConfira se extraiu todas as pastas e se index.html, css/, js/ e assets/ estão no mesmo nível. Abra F12 → Console.
FPS sem movimentoClique no jogo para ativar foco e experimente WASD. Use Esc para sair.
Textura ausenteReimporte a imagem e salve novamente o mapa JSON.
Layout sumiuVeja se houve limpeza dos dados do navegador ou troca de perfil. Importe seu backup JSON.
Mapa não abreVerifique se selecionou o JSON do mapa, não o JSON de layouts.

11. Roteiro de testes sugerido

Crie um corredor com jogador e porta; jogue, volte, adicione a chave correspondente; jogue novamente; colete a chave, abra a porta, salve o mapa, atualize a página e reabra o JSON. Depois mova painéis e teste restaurar o layout. Se alguma etapa falhar, anote os passos e abra uma Issue no GitHub.

12. O que ainda não existe

Exportação independente de EXE, multiplayer, editor completo de armas, animações avançadas, IA sofisticada, níveis 3D de alturas diferentes e editor visual de eventos. São propostas futuras, não recursos disponíveis na v0.3.
